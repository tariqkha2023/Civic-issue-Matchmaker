# Bundled public GitHub issue snapshot

`public-issues-v1.json.gz` contains published public GitHub issue content, source
identity/freshness, original issue metadata, and the valid AI requirements already
cached by this project. It is a compressed JSON allowlist export, not a copy of
the development database. No local accounts, sessions, messages, bookmarks,
contributions, feedback, curator overrides, audit records, credentials, private
backups, staging records or running-job leases are included.

`public-issues-v1.manifest.json` records per-source counts, generation time,
extraction versions, and SHA-256 checksums. The archive also embeds a payload
checksum and the exact extraction prompt. The importer validates all content,
source URLs, cache fingerprints and versions before writing public records.

From `backend/`, after installing the backend dependencies and copying
`.env.example` to a new `.env`:

```bash
python -m app.snapshot setup
```

This restores the bundled issues/cache and generates your own local demo accounts.
Keep `ENABLE_WORKER=false` (the example default); running the app and browsing
cached recommendations requires no GitHub or OpenRouter API key.

For an existing installation, stop the backend/worker first and use:

```bash
python -m app.snapshot import
```

Repeated imports preserve stable local IDs and private data. They do not remove
issues absent from the snapshot or overwrite newer source content. Existing
complete-source project context, schedules and enablement remain local; caches
whose fingerprints differ from that local context are skipped. Updates preserve
local curator overlays. No notifications or paid API calls are generated by import.

To publish an updated bundle from an operator's populated database:

```bash
python -m app.snapshot export
```

The default path is resolved relative to this repository, independent of the
working directory. An explicit `.json.gz` path may follow `export`, `import` or
`setup`. Review the manifest and public-only diff before committing an updated
bundle. Unprocessed issues remain unprocessed; setup never launches enrichment.
